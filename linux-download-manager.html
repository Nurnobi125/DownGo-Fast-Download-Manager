Linux installation guide

How to install DownGo on Linux Mint or Ubuntu

  1. Download downgo_4.1.1_amd64.deb using the button above.
  2. Open your Downloads folder and double-click the downloaded .deb file.
  3. Choose the Software Install or package installer option, then select Install. Enter your system password if prompted.
  4. After installation, open DownGo from the applications menu.

Install from Terminal

If the package is in your Downloads folder, open Terminal and run:

cd ~/Downloads
sudo apt install ./downgo_4.1.1_amd64.deb

Using apt install ./package.deb lets APT resolve available dependencies. If installation reports an unmet dependency, first run sudo apt --fix-broken install, then retry the install command.

Only install packages from sources you trust. This package is intended for compatible 64-bit Debian-based systems; it is not an RPM package for Fedora or openSUSE.
