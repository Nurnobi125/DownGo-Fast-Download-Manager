DownGo Browser Integration

Grab links from a webpage

Find links on a webpage, review the results, and send selected downloads to the DownGo Windows app.

Scan and choose

DownGo Browser Integration includes a “Grab All Links on Page” action. It scans the current browser page for supported links, lets you review and select items, and sends your choices to DownGo on the same computer. In the desktop app, the Grab Links tool can inspect supported sources and help add eligible downloads to your queue.

How to use it

  1. Install DownGo from Microsoft Store and start the desktop app.
  2. Install the official DownGo Browser Integration extension from the Chrome Web Store.
  3. Open a webpage you are allowed to download from and choose “Grab All Links on Page” in the extension.
  4. Review the detected links, select the files you want, and send them to DownGo.

Limits and privacy

The tool works with links exposed to the browser and supported by DownGo. It cannot guarantee discovery of links hidden behind scripts, sign-in requirements, site restrictions, or protected playback. Scanning is user initiated; the extension sends selected links to the local desktop app.

Use link collection only for content you are authorized to access and download. Read the browser integration guide and privacy policy.
