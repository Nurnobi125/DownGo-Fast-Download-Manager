DownGo Help Center

Set Up DownGo Browser Integration

Connect the browser extension to the DownGo Windows download manager on the same computer.

Install and connect

  1. Install DownGo from its official Microsoft Store listing and open the desktop app.
  2. Install DownGo Browser Integration from the official Chrome Web Store listing.
  3. Open the extension popup and check that the desktop app connection shows Connected.
  4. If it shows disconnected, make sure DownGo is running and choose Check Connection in the extension.

Send a download to DownGo

Right-click a supported download link and choose the DownGo option, or use Grab All Links on Page to review links before sending them. Auto-Capture is optional; turn it on only if you want matching browser downloads handed off automatically.

Video panel availability

The optional Video Download Panel works only when a webpage exposes media in a supported format and the browser allows the extension to inspect it. YouTube, DRM-protected streams, and HLS playlists are not supported by this extension panel, and it may not appear on some sites.

Privacy and permissions

Selected download information is sent to DownGo over the local connection on your PC. Matching cookies may be used only when required for a download you request. Read the privacy policy and extension details for more information.

If the bridge still does not connect, restart the desktop app and browser, then contact DownGo support.
