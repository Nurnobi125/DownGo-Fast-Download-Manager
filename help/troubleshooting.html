Troubleshooting Download Errors & Fixes

If a download stops, fails, or fails to resume, consult this diagnosis guide to understand the error cause and find the recommended solution.

1. HTTP 403 Forbidden (Expired Link / Token)

Many file hosting services and video streaming CDNs generate temporary download links with short expiration timers (e.g. 1 to 2 hours). If your download pauses and resumes after the token expires, the server returns HTTP 403 Forbidden.

Fix: Right-click the failed task in DownGo and select Refresh Link. Re-visit the original download page in your browser, copy the new link, paste it into the prompt, and click Update. DownGo will resume from your existing downloaded bytes without restarting.

2. HTTP 429 Too Many Requests (Rate Limiting)

Some servers restrict how many concurrent requests an IP can make. If you configure DownGo to use 32 parallel connections on an aggressive host, the server may temporarily reject requests with HTTP 429.

Fix: Go to Settings > Performance and switch the Acceleration Profile to Balanced or reduce parallel connections to 4 or 8. DownGo's built-in Adaptive Gate will automatically back off when it detects rate limits.

3. Connection Timed Out / Network Dropped

This occurs when the remote server is overloaded or your local Wi-Fi drops momentarily. DownGo features exponential backoff auto-retry. Check that your internet connection is active, then right-click the task and select Resume.

4. Resume Not Supported by Server

If the remote host ignores HTTP Range headers (Accept-Ranges: bytes), the file cannot be divided into multi-part chunks or resumed after pausing. DownGo will notify you with Resume support: No. If paused, single-stream downloads must start from the beginning.

5. Disk Space & Write Permission Errors

Before beginning large multi-gigabyte transfers, ensure your target drive has at least 15% free headroom. If you are downloading to an external USB drive, verify that the drive has write permissions enabled and is formatted with NTFS or exFAT (FAT32 has a strict 4 GB file size limit).

6. SHA-256 Checksum Mismatch

If DownGo alerts you to a checksum mismatch, the downloaded file's cryptographic hash does not match the publisher's stated hash. This indicates a truncated transfer or server-side corruption. Delete the partial file and re-download from the official source.
